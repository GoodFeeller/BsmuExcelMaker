# BsmuExcelWorker

Десктоп-приложение для просмотра Excel-расписания и выделения фрагмента для последующего экспорта в Word.

## Возможности (этап 1)

- Открытие файлов `.xlsx`, `.xlsm` и `.xls`
- Просмотр всех листов книги через вкладки
- Выделение диапазона ячеек мышью (как в Excel)
- Отображение адреса выделения в статус-баре (например, `B2:D8`)
- Агрегация выделенного фрагмента по группам (время, преподаватели, ответственные, кабинеты)

## Требования

- Python 3.10+
- Windows (основная платформа)

## Установка

```bash
pip install -r requirements.txt
```

## Запуск

```bash
python main.py
```

## Сборка EXE

```bash
pyinstaller build.spec
```

Готовое приложение будет в папке `dist/BsmuExcelWorker/`. Запускайте `BsmuExcelWorker.exe`.

## Использование

1. Запустите приложение
2. Меню **Файл → Открыть** (или `Ctrl+O`)
3. Выберите Excel-файл расписания
4. При необходимости переключитесь на нужный лист
5. Выделите фрагмент расписания мышью — справа появятся агрегированные данные по группам

## Формат выделения для агрегации

Таблица использует фиксированные столбцы Excel:

| Поле | Столбец |
|------|---------|
| Симуляционный кабинет | **B** |
| Обучающиеся (часть группы) | **E** |
| № образовательной программы (часть группы) | **F** |
| Альтернатива, если F пуст | **G** |
| Преподаватель | **J** |

**Группа** = **E** + **F**; если **F** пуст — **E** + **G** (например, `ПК 861` или `ПК 525`). Номер из F не наследуется из строки выше.

| Группа | Время | Преподаватель | Ответственный специалист | Симуляционные кабинеты |

Если в строке группа пустая, используется значение из предыдущей строки. Несколько строк с одной группой объединяются в одну запись.
