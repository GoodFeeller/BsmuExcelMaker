# RCPCST Sheduler

Десктоп-приложение для формирования дежурства и сводной информации. Архитектура **MVC**: оболочка приложения и отдельные модули.

## Разделы

1. **Формирование дежурства** — Excel-расписание, агрегация по группам, экспорт в Word
2. **Формирование сводной информации по дежурству** — импорт «2. Подсчет.xlsx», экспорт «3. Сводная информация.docx»

## Возможности (модуль «Дежурство»)

- Открытие файлов `.xlsx`, `.xlsm` и `.xls`
- Просмотр всех листов книги через вкладки
- Выделение диапазона ячеек мышью (как в Excel)
- Отображение адреса выделения в статус-баре (например, `B2:D8`)
- Агрегация выделенного фрагмента по группам (время, преподаватели, ответственные, кабинеты)
- Экспорт результата в Word по шаблону `assets/word_template.docx`

## Требования

- Python 3.10+
- Windows (основная платформа)

## Использование

1. Запустите приложение
2. На главном экране откройте **Формирование дежурства**
3. **Открыть файл** (или `Ctrl+O`) и выберите Excel-расписание
4. При необходимости переключитесь на нужный лист
5. Выделите фрагмент расписания мышью — справа появятся агрегированные данные по группам
6. На панели инструментов укажите **дату отчёта** и **дежурного специалиста** (в Word — 14 pt, строка «по состоянию на …»)
7. На вкладке **Ответственные** задайте привязку специалистов к кабинетам
8. **Экспорт** на панели модуля — сохраняет в одну папку:
   - `1. Информация для слушателей.docx` (агрегированная таблица для слушателей)
   - `2. Подсчет.xlsx` (фрагмент расписания + колонки для подсчёта посещений)
9. **← Главная** — возврат к выбору раздела

## Модуль «Сводная информация»

1. На главном экране откройте **Формирование сводной информации по дежурству**
2. Укажите **дату отчёта** и **дежурного специалиста** (те же настройки, что и в модуле дежурства)
3. **Открыть подсчёт** — выберите файл `2. Подсчет.xlsx` (лист с колонками кабинет, план, посещения, категории)
4. Проверьте сводные показатели на экране
5. **Экспорт** — сохраняет `3. Сводная информация.docx` по шаблону `assets/summary_template.docx` в ту же папку, что и файл подсчёта

Итоговые суммы (план, факт, подушно, категории) берутся из строки итогов файла подсчёта. Количество групп считается по уникальным сочетаниям «обучающиеся + № программы» и отдельным категориям без номера программы.

## Формат выделения для агрегации

Таблица использует фиксированные столбцы Excel:

| Поле | Столбец |
|------|---------|
| Симуляционный кабинет | **B** |
| Обучающиеся (часть группы) | **E** |
| № образовательной программы (часть группы) | **F** |
| Альтернатива, если F и H пусты | **G** |
| Альтернатива, если F пуст | **H** |
| Преподаватель | **J** |

На вкладке **Ответственные специалисты** задаётся, кто отвечает за какие кабинеты (например, `А` — `401, 402, 412`, `Б` — `502, 503`). В агрегации и в Word подставляется только имя из этой таблицы по номеру кабинета. Список сохраняется в кэш автоматически; доступны **Импорт JSON** и **Экспорт JSON**.

**Название группы** в таблице всегда **E** + **F**. Строки объединяются по **E** + **F**; если **F** пуст — по **E** + **H**; если **H** тоже пуст — по **E** + **G**. Значения из F, G и H не наследуются из строки выше.

| Группа | Время | Преподаватель | Ответственный специалист | Симуляционные кабинеты |

Если в строке группа пустая, используется значение из предыдущей строки. Несколько строк с одной группой объединяются в одну запись. Время, преподаватели, ответственные и кабинеты выравниваются построчно (при нехватке строк в одной колонке подставляются пустые). Группы сортируются по началу занятия.

## Структура проекта (MVC)

```
app/
├── mvc/                    # базовые Model / View / Controller
├── shell/                  # главное окно, домашний экран
├── modules/
│   ├── duty_formation/     # формирование дежурства (model, view, controller, widgets, services)
│   └── duty_summary/       # сводная информация (model, view, controller, services)
├── app_paths.py, styles.py, …  # общие утилиты
main.py
```
